# TodoenTextiles
página promocional
 🚀 Agregar Nuevo Producto
Paso 1: Acceso al Panel
Abre el archivo admin.html en tu navegador

Inicia sesión si es requerido

Paso 2: Iniciar Creación de Producto
Haz clic en el botón "Agregar Nuevo Producto"

Se abrirá un formulario modal

Paso 3: Completar Información Básica
Rellena los campos del formulario:

Nombre: Conjunto 5 Femenino

Categoría: Selecciona Femenino o Masculino

Imagen: img/products/F5.png

Tela: Algodón

Estructura: Descripción detallada de la prenda

Paso 4: Configurar Colores
Para cada color del producto:

Haz clic en "Agregar Color"

Completa los campos:

Parte: "Blusa" (ejemplo)

Color: Selecciona con el selector de color o ingresa #ff6b6b

Nombre: "Rojo coral" (ejemplo)

Repite este paso para todos los colores disponibles

Paso 5: Guardar Producto
Haz clic en "Guardar"

✅ Éxito: El producto aparecerá inmediatamente en el catálogo principal

✏️ Editar Productos Existentes
Paso 1: Localizar Producto
En el panel de administración, busca el producto que deseas modificar

Identifícalo en la lista de productos

Paso 2: Iniciar Edición
Haz clic en el botón "Editar" del producto seleccionado

Se abrirá el formulario con los datos actuales

Paso 3: Realizar Modificaciones
Modifica los campos necesarios:

Puedes cambiar nombre, categoría, imagen, tela o estructura

Agregar o eliminar colores según sea necesario

Paso 4: Guardar Cambios
Haz clic en "Guardar"

✅ Éxito: Los cambios se aplicarán inmediatamente en el catálogo

🗑️ Eliminar Productos
Paso 1: Localizar Producto
En el panel de administración, busca el producto que deseas eliminar

Identifícalo en la lista de productos

Paso 2: Iniciar Eliminación
Haz clic en el botón "Eliminar" del producto seleccionado

Aparecerá un cuadro de confirmación

Paso 3: Confirmar Acción
⚠️ Advertencia: Esta acción no se puede deshacer

Confirma la eliminación en el diálogo de confirmación

Paso 4: Verificación
✅ Éxito: El producto se eliminará permanentemente del catálogo

Verifica que ya no aparece en la lista de productos

📝 Notas Importantes
🔸 Sobre las Imágenes
Asegúrate que las rutas de imágenes sean correctas

Las imágenes deben estar previamente cargadas en la carpeta img/products/

Formatos recomendados: PNG, JPG, WebP

🔸 Sobre los Colores
Cada producto puede tener múltiples colores

Cada color requiere: parte, valor hexadecimal y nombre descriptivo

Usa el selector de color para elegir tonos exactos

🔸 Sobre la Categoría
Los productos se filtrarán automáticamente según su categoría

Asegúrate de seleccionar la categoría correcta para una navegación óptima
